# TradePocket

An offline stock trading course, from beginner to pro, in a single web page.

- 25 lessons in 4 levels (Beginner, Intermediate, Advanced, Pro), each with a quiz
- Paper-trading simulator with stop-loss / take-profit, SMA and RSI
- Quick Quiz, trading calculators, glossary and flashcards
- Works offline once opened (installable to the home screen)

## Use on iPhone
1. Open the GitHub Pages link in **Safari**.
2. Tap **Share → Add to Home Screen**.
3. Open it once from the home screen while online; after that it works with no internet.

Progress is saved on each device. For education only, not financial advice.
